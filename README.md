# 🎮 N-Server Monitor

Мониторинга Minecraft-сервера **N-server**, написанная на **TypeScript/JavaScript**. Позволяет в реальном времени отслеживать онлайн, рассчитывать часы игры каждого игрока и модератора, а также быстро узнавать, кто сейчас находится на сервере.
> 🤖 Проект разработан с использованием нейросетей.

## ✨ Возможности

- 📊 **Мониторинг онлайна**
- ⏱️ **Расчёт часов игры**
- 👀 **Просмотр активных игроков**
- 📈 **Статистика по модераторам**
